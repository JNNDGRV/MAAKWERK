# MAAKWERK

Kleine statische website — `index.html` staat in de projectroot (belangrijk voor Netlify).

Snelstart
- Lokaal bekijken: `open index.html` of `python3 -m http.server 8000` en ga naar http://localhost:8000
- Wijzig HTML/CSS in de root en refresh de pagina.

Deploy (Netlify)
- Verbind de GitHub-repo met Netlify of gebruik drag & drop.
- Publish directory: `/` (root). Geen build command nodig.

Projectstructuur
- `index.html`, `over-ons.html`, `realisaties.html`, `contact.html`
- `assets/css/`, `assets/js/`, `assets/images/`

Git
- `git add . && git commit -m "..." && git push`

Wil je dat ik echte beelden/lettertypes toevoeg of meer deploy‑configs maak, zeg het kort.
